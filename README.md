# AI-Powered-Network-Security-Reconnaissance-Tool
NetSentinel is an intelligent cybersecurity assistant built to automate and simplify security operations using AI.
the tool assists with OSINT collection, vulnerability analysis, threat intelligence, and network reconnaissance through an interactive terminal interface

**Installation**


git clone https://github.com/ErfaisalBhat/AI-Powered-Network-Security-Reconnaissance-Tool

cd ai-network-assistant

**Create Virtual Environment**


python3 -m venv myenv
source myenv/bin/activate

Install Dependencies
pip install -r requirements.txt

**Setup API Key**

Create a .env file in the project directory:

GROQ_API_KEY=your_api_key_here

**Run the Project**

python main.py
